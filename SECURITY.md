# Security Policy

## Supported Versions

This project is currently a public starter/accelerator and does not yet maintain
strict long-term support branches. Security fixes are applied to the `main`
branch.

## Reporting a Vulnerability

If you discover a security issue, please do **not** open a public issue.

Instead, report it privately using one of these channels:

- GitHub private vulnerability reporting (Security Advisories), if enabled
- A direct message to the repository owner on GitHub

Please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested remediation

We will acknowledge receipt as soon as possible and work on a fix before public
disclosure.
